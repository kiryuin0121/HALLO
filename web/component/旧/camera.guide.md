# カメラアングル調整ガイド

## 📐 基本的な座標系

Three.jsの座標系：
- **X軸**: 左右（正の値 = 右、負の値 = 左）
- **Y軸**: 上下（正の値 = 上、負の値 = 下）
- **Z軸**: 前後（正の値 = 前、負の値 = 後ろ）

アバターは常にZ軸の正の方向（前方）を向いて移動します。

## 🎥 カメラの2つの重要なパラメータ

### 1. `offset` - カメラの位置（アバターからの相対位置）

```javascript
offset: new Vector3(X, Y, Z)
```

#### X値（左右の位置）
- **0**: カメラが真後ろ（センター）
- **1.5**: カメラが右後ろ（肩越し視点）
- **-1.5**: カメラが左後ろ
- **推奨範囲**: -2 ～ 2

#### Y値（高さ）
- **2**: 低めのカメラ（ダイナミック、臨場感）
- **3～4**: 標準的な高さ（バランス良い）
- **5～6**: 高めのカメラ（見下ろし、戦略的）
- **推奨範囲**: 1.5 ～ 7

#### Z値（前後の距離）
- **-4**: 近い（アバターが大きく見える）
- **-6～-7**: 標準的な距離
- **-9～-10**: 遠い（周囲が広く見える）
- **推奨範囲**: -3 ～ -12
- ⚠️ **必ず負の値**（正の値だとアバターの前に来る）

### 2. `lookAtOffset` - カメラが見る位置（アバターのどこを見るか）

```javascript
lookAtOffset: new Vector3(X, Y, Z)
```

#### X値（見る位置の左右）
- **0**: アバターの中心を見る
- **0.5**: アバターの右側を少し見る
- **-0.5**: アバターの左側を少し見る
- **推奨範囲**: -1 ～ 1（基本は0）

#### Y値（見る高さ）
- **0**: アバターの足元を見る
- **1.2～1.5**: 腰～胸を見る（標準）
- **2**: 頭を見る
- **推奨範囲**: 0.5 ～ 2.5

#### Z値（見る位置の前後）
- **0**: アバターの現在位置を見る（標準）
- **2～3**: アバターの進行方向を見る（肩越し視点）
- **-1**: アバターの少し後ろを見る
- **推奨範囲**: -1 ～ 3

## 🎬 よくあるカメラアングルの作り方

### パターン1: 真後ろから見る（基本）
```javascript
offset: new Vector3(0, 3, -6),      // 真後ろ、やや上、中距離
lookAtOffset: new Vector3(0, 1.5, 0) // アバターの胸を見る
```

### パターン2: 肩越し視点（没入感）
```javascript
offset: new Vector3(1.5, 2.5, -4),   // 右肩後ろ、やや低め、近い
lookAtOffset: new Vector3(0, 1.8, 2) // 頭の高さで前方を見る
```

### パターン3: 高めの俯瞰視点（戦略的）
```javascript
offset: new Vector3(0, 6, -8),      // 真後ろ、高め、やや遠い
lookAtOffset: new Vector3(0, 1, 0)  // アバターの腰を見る
```

### パターン4: 低めのダイナミック視点
```javascript
offset: new Vector3(0, 1.5, -5),    // 真後ろ、低め、中距離
lookAtOffset: new Vector3(0, 1.2, 0) // 少し上を見上げる
```

## 📊 組み合わせの効果

### カメラを近づけたい
- Z値を **-3 ～ -5** に（例: -6 → -4）
- アバターが大きく見える
- 迫力が出る

### カメラを遠ざけたい
- Z値を **-8 ～ -12** に（例: -6 → -9）
- 周囲が広く見える
- 戦略的な視点

### カメラを高くしたい
- Y値を **5 ～ 7** に（例: 3 → 5）
- 見下ろす感じ
- 周囲の状況が把握しやすい

### カメラを低くしたい
- Y値を **1.5 ～ 2.5** に（例: 4 → 2）
- アバターと同じ目線
- 臨場感が出る

### 肩越し視点にしたい
- X値を **1.5 ～ 2** に（例: 0 → 1.5）
- lookAtOffset の Z値を **2 ～ 3** に
- 前方が見やすくなる

## 🔧 その他のパラメータ

### FOV（視野角）
```javascript
<PerspectiveCamera fov={60} />
```

- **50**: 望遠（ズームイン、アバターが大きく）
- **60**: 標準（バランス良い）
- **70**: 広角（視野が広い、アバターは小さめ）
- **推奨範囲**: 50 ～ 75

### 追従の滑らかさ
```javascript
lookAtPosition.current.lerp(targetLookAt, 0.1);
camera.current.position.lerp(desiredCameraPos, 0.1);
```

- **0.05**: ゆっくり追従（滑らか、少し遅れる）
- **0.1**: 標準
- **0.2**: 素早く追従（カクカクする可能性）
- **推奨範囲**: 0.05 ～ 0.15

## 🎯 実践例

### 例1: もっと近くで見たい
```javascript
// 変更前
offset: new Vector3(0, 4, -7)

// 変更後（2メートル近づく）
offset: new Vector3(0, 4, -5)
```

### 例2: もっと高い位置から見たい
```javascript
// 変更前
offset: new Vector3(0, 4, -7)

// 変更後（1.5メートル高く）
offset: new Vector3(0, 5.5, -7)
```

### 例3: 肩越しに変更したい
```javascript
// 変更前
offset: new Vector3(0, 3, -6)
lookAtOffset: new Vector3(0, 1.5, 0)

// 変更後（右肩越し）
offset: new Vector3(1.5, 2.5, -4)
lookAtOffset: new Vector3(0, 1.8, 2)
```

## 💡 調整のコツ

1. **まず距離（Z値）を調整** → 近い/遠いを決める
2. **次に高さ（Y値）を調整** → 見下ろす/同じ目線を決める
3. **必要なら左右（X値）を調整** → 肩越し視点にするか決める
4. **lookAtOffsetで微調整** → 見る位置を調整
5. **FOVで最終調整** → ズーム感を調整

## ⚠️ 注意点

- offset の Z値は**必ず負の値**（正だとアバターの前に来る）
- 極端な値は避ける（-20とか20とか）
- 変更したら実際に動かして確認
- 移動中と停止中の両方で確認すると良い
